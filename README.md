# 노주훈 포트폴리오

기존 사진 카루셀, 로고와 코랄·옐로 색상을 유지하며 경력 내용을 보완하는 포트폴리오입니다. 첫 화면은 `프론트엔드 개발자 / 노주훈입니다.`로 소개합니다.

## 개발

Next.js 14.2.5 · React 18 · TypeScript를 사용합니다. Node는 20.9 이상이 필요하며 CI는 Node 20을 사용합니다. 패키지 관리자는 npm입니다.

```sh
npm ci
npm run dev
npm run lint
npm run build
```

Next 14의 린트와 호환되는 ESLint 8.57.1을 사용합니다. 타입 검사 범위는 `src`와 Next 생성 타입입니다. 과거 프로젝트를 모아 두었던 `project/` 폴더는 제거했습니다. 개인 프로젝트는 별도 저장소에서 관리합니다. 과거 자료인 `blog/`는 현재 앱 빌드 대상이 아닙니다. 회사 소스나 인증정보를 포트폴리오 사례에 재사용하지 않습니다.

## 화면 구성

- 메인: 사진 카루셀 → About → Work → Experience → Contact.
- 퍼블리싱은 별도 직무 섹션 대신 소개 안에서 HTML·CSS·접근성·반응형 UI의 기본기로 짧게 설명합니다.
- 링크에는 방향 아이콘 대신 밑줄과 색상을 사용합니다. 카루셀 이전·다음 버튼은 별도의 조작 컨트롤입니다.
- 카루셀은 기존 `banner_1.jpg`부터 `banner_3.jpg`를 사용하며 이전·다음 버튼, 방향키, 포인터 드래그를 지원합니다. 자동 재생은 하지 않습니다.
- 본문 배경 이미지 4장을 제거하고 하나의 밝은 읽기 영역으로 정리합니다. 사진은 첫 화면 카루셀에만 사용합니다.
- 목록은 회사·기간·제목·요약으로 간소화하고 상세 기술은 사례 페이지에 표시합니다.
- 기술 스택은 `src/content/skills.ts`에서 관리하며 프론트엔드·구조 설계부터 품질·배포·제품 분석·플랫폼·접근성 순으로 묶습니다. Vitest, GA4, PostHog, GEO 및 앱 배포 경험은 사용자 확인 내용에 따라 추가했습니다.
- AI 하네스 구성 경험은 사용자 제공 프로젝트 설명을 바탕으로 `src/content/ai-harness.ts`에 정리하고, 기술 스택의 기본 닫힘 상태인 details에서 표시합니다. 내부 저장소 경로와 조직명은 노출하지 않으며 생산성 개선 수치를 임의로 추가하지 않습니다.
- 본문은 등장 애니메이션과 제목 고정 없이 일반 문서 스크롤을 사용합니다.
- 기존 미완성 문구를 경력 설명으로 교체하고 일반 문서 스크롤과 앵커 이동을 사용합니다.
- 프로젝트 목록 정보는 `src/content/projects.ts`, 상세 설명은 `src/content/case-studies.ts`에서 관리합니다.
- 상세 사례는 `/projects/deepmedi-admin/`, `/projects/kiwisnap-editor/`, `/projects/haii-mfe/`, `/projects/tizen-tv/`로 정적 생성됩니다.
- 개인 앱 하루일기는 `/projects/harudiary/`로 정적 생성하며 메인의 개인 프로젝트에서 연결합니다. 앱 소개 전용 페이지로, AI 하루와 나눈 대화가 일기가 되는 경험·기획 의도·주요 기능·정식 출시와 운영 현황을 소개하고 App Store·Google Play·인스타그램으로 연결합니다.
- 하루일기 상세 작업 계획과 TODO·검증 기록은 `docs/plans/harudiary-detail.md`에서 관리합니다.
- 앱 소개 중심의 개편 계획과 이미지 자료 TODO는 `docs/plans/harudiary-app-intro.md`에서 관리합니다.
- 하루일기 상세에는 실제 스토어 소개 이미지 5장을 원본 비율로 표시하며, 메인 개인 프로젝트에는 하루 캐릭터 썸네일을 사용합니다. 이미지는 `public/images/harudiary/`에서 관리합니다.
- Work 상세 4개는 본문에 집중하도록 상단 ‘대표 프로젝트로’ 링크와 하단 푸터를 표시하지 않습니다.

MFE 소속은 2026-10-28 사용자 확인에 따라 하이(Haii)입니다. 업무 성과 수치는 제공된 이력서 기준이며 이번 작업에서 새로 측정하지 않았습니다. 내부 검토용 문구는 사이트에 노출하지 않습니다. 회사 소스와 미승인 스크린샷을 포함하지 않으며, Java/Spring 실무 경력은 추가하지 않았습니다.

하루일기는 Flutter 개인 앱으로, 다운로드 및 인스타그램 링크를 연결합니다. 2026.10 사용자 설명 기준 누적 가입자 약 70~80명, 월구독 결제 1건입니다. 활성 사용자·다운로드 수나 반복 매출로 해석하지 않습니다. 스마트팜 과정(2024.05~2024.11)은 재직 이력과 구분해 교육 이수·팀 프로젝트로 표시합니다.

## 배포와 연락

`output: "export"`, `trailingSlash: true`를 사용해 `out/`을 생성합니다. master 브랜치에 반영하면 기존 GitHub Actions가 GitHub Pages로 배포합니다. 개발 브랜치와 PR의 검증 워크플로는 배포하지 않습니다.

포트폴리오는 EC2를 사용하지 않는 정적 호스팅을 유지합니다. Pages 빌드에 기존 EC2 API 주소를 주입하지 않으며 연락은 이메일 링크로 제공합니다. `/contact/`의 기존 폼 구현은 보존하되 `NEXT_PUBLIC_EC2_INSTANCE_PUBLIC_IP`가 별도로 설정된 경우에만 표시합니다. 실제 API 연결과 이메일 전송은 검증하지 않았습니다. AWS 자원은 중지·삭제하지 않았습니다.

# 하루일기 상세 페이지 — 앱 소개로 전환

작성일: 2026-10-29 (Asia/Seoul)

## 목표

하루일기가 무엇을 하는 앱인지, 어떤 경험을 제공하는지, 실제로 출시해 운영하고 있다는 점을 전달한다. 기술 스택·백업 구조·결제 동기화 등 경력 사례와 중복되는 구현 설명은 상세 페이지에서 제거한다.

## 페이지 구성

1. 앱 소개: 일기 쓰기가 어려운 사람이 AI 하루와 대화하면 대화 내용이 일기로 기록되는 앱. 사용자 확인 문구를 핵심 가치로 사용한다.
2. 기획 의도: 무엇부터 써야 할지 막막한 순간에도 기록을 시작하도록 돕는 경험.
3. 사용 흐름: AI 하루와 대화하기 → 대화가 일기로 기록되기 → 지난 기록 돌아보기.
4. 주요 경험: 음성 입력·손글씨 사진 변환·기록 탐색·한 달 돌아보기.
5. 정식 출시: App Store·Google Play 링크와 기존 운영 현황.

## 근거와 범위

- 하루팩토리의 기존 앱 소개·다운로드 페이지에 있는 공개 설명과 스토어 주소를 사용한다.
- 사용자 조사 결과나 효과 수치, 출시일, 후기 등 확인되지 않은 내용은 만들지 않는다.
- 가입자·결제 수치는 기존 2026.10 기준을 유지한다.
- 앱 소개 전용 페이지를 만들고 경력 사례 4개의 기존 템플릿과 구분한다.
- 이미지가 오기 전에는 실제 앱 화면처럼 보이는 가짜 이미지를 만들거나 빈 이미지 상자를 노출하지 않는다.

## 필요한 이미지

- 앱 아이콘 또는 대표 썸네일 1장.
- AI 하루와 대화하며 쓰는 화면, 작성된 일기, 한 달 돌아보기 화면 등 세로 스크린샷 3~4장.
- 화면마다 어떤 기능인지 알 수 있는 짧은 설명. 순서는 대화 → 기록 → 돌아보기.

## 검증 기록

- 사용자에게 핵심 가치(대화 내용이 일기로 기록되는 앱)를 확인했다.
- 하루팩토리의 기존 앱 소개와 다운로드 안내에 있는 기능·스토어 주소를 확인했다.
- 상세 페이지를 별도 정적 경로로 만들고 경력 사례 템플릿에서 개인 앱의 기술 설명을 제거했다.
- 이미지 구성은 자료 수령 후 진행한다. 현재 페이지에 가짜 스크린샷이나 이미지 준비 문구를 넣지 않는다.

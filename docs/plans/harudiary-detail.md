# 하루일기 포트폴리오 상세 페이지 계획

작성일: 2026-10-29 (Asia/Seoul)

## 목표

메인의 하루일기 소개를 `/projects/harudiary/` 상세 페이지로 연결한다. 기능 나열보다 개인 앱의 개발·출시·운영과 기술적 선택을 설명한다. 기존 경력 사례 4개와 개인 프로젝트 목록의 구분을 유지한다.

## 콘텐츠 원칙

- 기존 사이트에 기록된 Flutter 앱 출시·운영 경험과 2026.10 기준 누적 가입자 약 70~80명, 월구독 결제 1건을 사용한다. 활성 사용자·다운로드·반복 매출로 확대 해석하지 않는다.
- 비공개 앱 저장소는 사실 확인에만 사용한다. 소스, 설정값, 내부 식별자, 사용자 데이터, 비공개 저장소 링크를 공개 페이지에 넣지 않는다.
- 구현된 기능과 실제 배포·운영 성과를 구분하고, 미확인 성능·보안 효과는 주장하지 않는다.
- 기존 디자인을 재사용하고 상세 보기·앱 다운로드·인스타그램의 목적을 구분한다.
